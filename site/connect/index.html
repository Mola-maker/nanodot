Shared limits共享限制

  • All authorized clients share 40 AI attempts per UTC day. Each client has 12 attempts per rolling 60 seconds. Failed or cancelled admitted attempts stay counted.所有授权客户端合计每天（UTC）最多 40 次 AI 尝试；每个客户端每滚动 60 秒最多 12 次。已准入的失败或取消请求仍计数。
  • Body ≤ 4 MiB; text context ≤ 16,000 characters; output ≤ 2,048 tokens.请求体 ≤ 4 MiB；文字上下文 ≤ 16,000 字符；输出 ≤ 2,048 tokens。
  • One client-reencoded PNG/JPEG ≤ 2 MiB and 1280 px per side.一张经客户端重编码的 PNG/JPEG ≤ 2 MiB，每边 ≤ 1280 px。
  • Independent PCM16 WAV, 16 kHz mono: ≤ 30 seconds / 2 MiB. Speech text limit, if verified later: ≤ 500 characters.独立 PCM16 WAV，16 kHz 单声道：≤ 30 秒 / 2 MiB。将来合成验证后的文本限制：≤ 500 字符。

These are application request limits, not a Neuron meter or an unlimited per-user allowance. Cloudflare’s Free account allocation is 10,000 Neurons/day, resetting at 00:00 UTC. The actual account must be verified Free before inference is enabled.这些是应用请求限制，不是 Neuron 计量，也不是每用户无限额度。Cloudflare Free 账号总额度为每天 10,000 Neurons，00:00 UTC 重置。启用推理前必须确认真实账号为 Free。 Cloudflare pricingCloudflare 定价

Understand errors了解错误

401 means project authorization is required; 429 means the shared budget was reached; 503 means configuration or a model service is unavailable. API errors return uncached JSON or an explicit streaming error. They never become a successful HTML homepage.401 表示需要项目授权；429 表示达到共享预算；503 表示配置或模型服务不可用。API 错误返回不缓存的 JSON 或明确的流错误，不会变成成功的 HTML 首页。
