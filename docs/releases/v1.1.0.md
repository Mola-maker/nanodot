# Nanodot 1.1.0 · Crystal

**Android preview · 2026-10-14.** Crystal is the first Nanodot release. It brings the blue crystal orb, foreground conversation, region questions and user-guided Care together in an Android arm64 package.

The orb stays above the current app. Open chat with one tap, Screen with two taps, or Care with three; long-press for the action menu. A closed drag selects a region. Care highlights a target and gives a temporary text cue while preserving the complete instruction in the bottom conversation. You perform the action and confirm steps when requested.

## Highlights

- **Crystal and cobalt glass.** A blue crystal identity, translucent foreground cards with drawn depth, a compact status indicator and separate Stop control. The effect uses transparent color and rendered edges, not cross-app optical refraction.
- **Region questions.** Circular, rectangular and irregular selections produce masked image previews. Image-capable models receive the selected pixels and question; other models retain the accessible-text fallback. Follow-up questions use the same conversation history.
- **Guided Care.** Target contours draw progressively; temporary text reveals and expires while the bottom instruction remains readable. Repeat replays the guidance without another planning request. Stop cancels pending work and rejects stale results.
- **Readable conversation.** Replies follow streaming growth and window shrink while preserving the reading position when you scroll back. Existing narrow-window, large-text and keyboard evidence is documented separately.

## Upgrade Notes

- Download **[Nanodot-1.1.0-arm64.apk](https://github.com/Mola-maker/nanodot/releases/download/v1.1.0/Nanodot-1.1.0-arm64.apk)** from this release. It targets Android 8.0+ / arm64-v8a, application ID `io.github.nanodot.app`, versionCode **45**, and uses a dedicated Nanodot release certificate. Android 14+ supports pixel capture; earlier systems use the documented accessibility-text route.
- Verify the APK using the accompanying `Nanodot-1.1.0-arm64.apk.sha256`. `Nanodot-1.1.0-build.json` records the exact source commit, APK and signing-certificate hashes, toolchain and evidence limits. The GitHub source archives correspond to tag `v1.1.0`; fetch the recorded `android/deps/proot` submodule for a complete source checkout.
- This is the first Nanodot release signing identity. Earlier debug builds with the same application ID use another certificate and cannot be overwritten by this package. Export anything you need before choosing to replace a debug installation; this release does not promise a verified data migration. Upstream nanoMuse is a separate app with separate storage.
- Configure your own model provider and explicitly enable accessibility when using the orb. Automatic updates and continuous voice remain off by default. `nanoMuse Cloud` retains its upstream name, account and service policies; Nanodot does not operate it or promise a free allowance.
- This release publishes the Android APK and source. Desktop, harness and iOS outputs require their own build and publication checks; no TestFlight availability, desktop download, website deployment or container publication is implied.

## Verification and preview limits

The linked [Android evidence](https://github.com/Mola-maker/nanodot/blob/v1.1.0/docs/android-verification.md) records API 35 x86_64 native navigation and local-planner Care tests, actual display sequences, continuous recordings and a separate real-provider region journey. Controlled image questions achieved **4/4 core facts**, but only **2/4 complete answers** were free of detected errors; two answers added an incorrect geometric detail.

Those runtime results retain their original development APK identities. They are not a claim that this new signed arm64 release was run on a physical device. This release remains a **prerelease**: a complete real-provider Care task reaching a verified endpoint, first-mount animation capture, arbitrary third-party apps, Chinese microphone recognition and audible speech, older Android runtime behavior, physical arm64 hardware and broader platform/localization acceptance remain open. Care currently plans from accessible controls; the image questions run in Screen chat, not a Care vision planner.

**Android 预览版 · 2026-10-14。** Crystal 是 Nanodot 的首次发布，将蓝色水晶球、前台对话、区域提问和用户执行的关怀引导整合到 Android arm64 安装包中。

单击球打开聊天，双击进入屏幕模式，连续三击进入关怀；长按可展开功能菜单，闭合拖动可选择区域。关怀会沿目标描边并显示短暂文字提示，同时在底部对话中保留完整指令。操作由你执行，需要确认时会明确提示。

### 亮点

- **水晶球与钴蓝玻璃。** 蓝晶身份、带绘制厚度的半透明卡片、轻量状态和独立停止按钮；不是跨应用真实光学折射。
- **区域提问。** 圆形、矩形、不规则圈选生成遮罩预览。图像模型接收选区像素和问题，其他模型保留可访问文字回退；同一会话可继续追问。
- **关怀引导。** 目标轮廓逐段绘制，临时文字逐渐显示并消失，底部全文继续保留。重播不会再次请求规划；停止取消待处理工作并拒绝过期结果。
- **可读对话。** 回复随流式增长和窗口缩小保持末行可见，向上翻阅时保留阅读位置；窄屏、大字体和键盘的已有证据另有记录。

### 安装与升级

- 下载本发布中的 **[Nanodot-1.1.0-arm64.apk](https://github.com/Mola-maker/nanodot/releases/download/v1.1.0/Nanodot-1.1.0-arm64.apk)**：Android 8.0+、arm64-v8a、`io.github.nanodot.app`、versionCode **45**，使用独立 Nanodot 发布签名。Android 14+ 支持像素捕获；较早系统走文档说明的可访问文字路线。
- 配套 `.sha256` 用于校验 APK；`Nanodot-1.1.0-build.json` 记录准确源码、APK 和签名证书哈希、工具链及验证范围。对应源码为 `v1.1.0`，完整检出还需获取记录中的 `android/deps/proot` 子模块。
- 首次发布签名与以前 debug 包不同，同 applicationId 的 debug 包不能直接被覆盖。若选择替换 debug 安装，先导出所需数据；本次未承诺已验证的数据迁移。上游 nanoMuse 是存储独立的另一应用。
- 配置自己的模型服务商，并在使用悬浮球时明确开启无障碍。自动更新与连续语音默认关闭。`nanoMuse Cloud` 保留上游名称、账号和政策，Nanodot 不运营该服务，也不承诺免费额度。
- 本次发布 Android APK 与源码；桌面、harness、iOS 需独立构建和发布检查，不表示已提供 TestFlight、桌面安装包、网站部署或容器发布。

### 验证与预发布边界

[Android 验收记录](https://github.com/Mola-maker/nanodot/blob/v1.1.0/docs/zh/android-verification.md)包含 API 35 x86_64 上的真实主页导航、本地规划器关怀、实际连续帧和录屏，以及独立的真实服务商区域问答。受控图像题核心事实 **4/4**，完整答案仅 **2/4** 未发现错误，另两条含多说的几何细节错误。

运行结果仍绑定原开发 APK，不代表这个新签名 arm64 发布包已在实体手机运行。真实模型关怀任务到可证实终点、首次挂载动画全过程、任意第三方应用、中文麦克风识别及可听语音、旧 Android、arm64 真机和更广平台／语言仍待验收，因此标记为**预发布**。Care 当前依据可访问控件规划，图像问答发生在 Screen 聊天。
